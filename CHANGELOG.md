# Changelog

All notable changes to Radiata are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Changed

- Repository branding standardized as Radiata.
- Added Radiata icons for Firmware, Document Scanner, Language Support, Video Player, Characters, Help, and the LibreOffice suite (Start Center, Writer, Calc, Impress, Draw, Base, and Math).
- Added a dedicated Radiata AppImage MIME icon for Files, desktop file views, and file pickers.
- Fixed unreadable labels on GNOME logout, restart, and shutdown confirmation buttons.
- Styled file-action toast notifications and added Radiata icons for more default Ubuntu applications.
- Themed the GNOME authentication (sudo/polkit) password prompt with the dark surface, red avatar, password field, and buttons, using a single outer outline.

## [1.0.0] - 2026-11-13

### Added

- One-command Ubuntu GNOME installer and reversible uninstaller.
- Radiata Glass GTK 3, GTK 4, libadwaita, GNOME Shell, and GDM styling.
- Red matrix-rain Lycoris radiata wallpaper for the desktop, lock screen, and login screen.
- Transparent floating Ubuntu Dock and red GNOME panel, overview, date menu, and quick settings.
- Radiata application, folder, and system icon overrides with Papirus Dark fallback.
- Multi-size neon-red cursor family.
- Ptyxis, Bash, btop, fastfetch, and cmatrix integration.
- Recovery journal for GNOME settings and modified user files.
