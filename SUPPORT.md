# Support

Use GitHub Issues for reproducible Radiata problems.

Before opening an issue:

1. Confirm that the desktop session is GNOME on Ubuntu.
2. Run `gnome-shell --version` and `lsb_release -ds`.
3. Re-run `./install.sh` and capture the first error.
4. Check whether logging out and back in resolves Shell or cursor caching.
5. Read the limitations in `README.md`.

Attach screenshots directly to the issue. Remove usernames, hostnames, IP addresses, mounted-drive names, and other private information first.

Questions about modifying the palette belong in Discussions if the repository enables it.
