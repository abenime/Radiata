# Code of Conduct

## Our standard

Radiata welcomes contributors of every background and experience level. Be respectful, discuss technical disagreements in good faith, and give actionable feedback about the work rather than the person.

Unacceptable behavior includes harassment, discrimination, threats, deliberate intimidation, publishing another person's private information, or repeatedly disrupting project discussions.

## Enforcement

Report conduct concerns privately to the maintainer through the security contact described in `SECURITY.md`. The maintainer may edit or remove contributions and restrict participation when necessary to keep the project safe and productive.

## Scope

This code applies in the repository, issue tracker, pull requests, release discussions, and public spaces where someone represents Radiata.
